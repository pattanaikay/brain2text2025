SMOKE TEST 1: train_ssl.py
==========================
Run (single line, do not wrap):
py scripts/train_ssl.py --train_h5 "<HDF5_PATH>" --val_h5 "<HDF5_PATH>" --epochs 1 --batch_size 4 --num_workers 0 --output_dir .\local_checkpoints\ssl_smoke --patch_size 5

Notes:
- num_workers=0 is intentional: Windows multiprocessing inside DataLoader 
  sometimes hangs with HDF5; we want a clean serial run for smoke-testing.
- batch_size=4 is intentional: 6 GB VRAM safe.
- If the process exits with non-zero status, capture the FULL traceback 
  (stderr) and report it verbatim. Do not try to fix it without showing me first.

PASS CRITERIA for SSL smoke test:
- Process exits with code 0
- A file .\local_checkpoints\ssl_smoke\best_encoder_ssl.pth exists after the run
- A file .\local_checkpoints\ssl_smoke\checkpoint_ssl_latest.pth exists after the run
- Log contains "Epoch 1 val_loss:" (proves the new validation loop ran)
- Log contains the message about glob-discovered files OR "Found N train files" (proves 
  multi-file discovery executed even if N=1)

FAIL CRITERIA (treat as bug to fix in code):
- RuntimeError about meta tensors, dtype mismatch, or shape mismatch
- NameError or AttributeError (means an edit referenced a missing symbol)
- CUDA OOM (lower batch_size to 2 and retry ONCE; if still OOM, report)
- NaN or inf in loss (proves the masked-loss normalisation is broken)
